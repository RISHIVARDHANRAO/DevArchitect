# 🚀 DevArchitect AI

**DevArchitect AI** is a **Multi-Agent Software Engineering Assistant** powered by **IBM watsonx.ai**, **IBM Granite Models**, and **Python Flask**. It helps developers analyze, understand, secure, and optimize software repositories using Agentic AI and Retrieval-Augmented Generation (RAG).

## 🌟 Features

* 🤖 Multi-Agent AI Architecture
* 📂 GitHub Repository & ZIP Upload
* 🧠 AI-Powered Repository Analysis
* 🏗️ Architecture & Dependency Visualization
* 🔍 Intelligent Code Review
* 🛡️ Security Vulnerability Detection
* ⚡ Performance Optimization Suggestions
* 📖 Automatic README & Documentation Generation
* 💬 Repository Chat using RAG
* 📊 Repository Health Dashboard
* 🌙 Modern Responsive UI with Dark Mode

## 🏗️ Tech Stack

* **Backend:** Python, Flask
* **Frontend:** HTML, CSS, Bootstrap 5, JavaScript
* **AI Platform:** IBM watsonx.ai
* **Foundation Models:** IBM Granite Models
* **RAG:** FAISS / ChromaDB
* **Visualization:** Chart.js, Mermaid.js
* **Cloud:** IBM Cloud

## ⚙️ Installation

```bash
git clone https://github.com/<username>/DevArchitect-AI.git
cd DevArchitect-AI
python -m venv venv
```

Activate the virtual environment:

**Windows**

```bash
venv\Scripts\activate
```

**Linux/macOS**

```bash
source venv/bin/activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Create a `.env` file and configure:

```env
IBM_API_KEY=YOUR_API_KEY
IBM_PROJECT_ID=YOUR_PROJECT_ID
IBM_WATSONX_URL=https://us-south.ml.cloud.ibm.com
SECRET_KEY=YOUR_SECRET_KEY
```

Run the application:

```bash
python run.py
```

Open:

```
http://localhost:5000
```
